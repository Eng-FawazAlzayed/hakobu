Host special cases

How Hakobu deals with file hosts the way JDownloader does: waits the host asks for, retries, damaged files, files already on disk.

Limits per host for hosts that ban too many connections · 0 = no limit

Proxies

HTTP or SOCKS proxies for file hosts. "Always" carries that traffic; "Only to skip waits" is used when a host limits your IP (daily quota, "wait 30 minutes"), so the download moves on instead of waiting. Leave hosts empty for all hosts. Torrents don't use these.

Host accounts

Your own premium accounts, used before debrid for that host. Built in without an account: MEGA (files and folders), Pixeldrain, MediaFire, Google Drive, 1fichier (free, with waits), Send, DataNodes, KrakenFiles and BuzzHeavier. Accounts are encrypted with Windows DPAPI.

Plugin manager

Plugins add search results or a source under Source in the sidebar. Install one with the button, by double-clicking a .hakobu-plugin file, or by dropping it onto the window; share one with its upload button; switch it off to hide it, or remove it (it goes to the Recycle Bin). Plugins run with Hakobu's own rights, so only install ones you trust.
